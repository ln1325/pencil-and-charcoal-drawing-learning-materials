# pencil-and-charcoal-drawing-learning-materials
Pencil and charcoal drawing learning materials and references for art entrance exams.

# 美术联考素描素材

这些素材来自我的老师，他慷慨地向我们这些即将面对美术联考的同学们分享了他在这几年里收集到的素材。

> 比较适配广东省美术联考素描，对于其他地区的素描可能不适配。

在美术联考中素描考试时长为3小时，3小时能做的事比较有限，所以考试的画面可能跟平时长期作品的画面不一样，
但都是我们实际能力的体现
