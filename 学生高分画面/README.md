# 学生高分画面

此文件夹用于存放学生的高分素描作品。
## 画面优势
- 整体氛围感好，环境塑造完整，空间感强
- 物体质感塑造强，对反光、投影和笔触排线把握精准

## 可能存在的问题
- 部分作品可能存在透视不正确（看起来歪歪扭扭的）
  <ins>
      这一点大可不必太过于纠结，在广东省美术联考改卷过程中，一般在电脑上以缩略图形式显示考生的答卷图片，
      整体感做得好看，空间感强，就会让改卷老师对你的画面有好的第一印象，从而在第一次分档时上到75分以上的高档
  </ins>
- 物体塑造过于粗糙
  <ins>
      这一点等到改卷老师放大画面才会看到，依然可以用同样的做法：
      只要你环境塑造完整，空间感强，即使物体塑造不是很精美也可以得到高分
  </ins>
